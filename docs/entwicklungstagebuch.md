**Cascade-Layer-Bug in `base.css` gefunden und behoben.** Beim Versuch, den Abstand zwischen Überschrift-Card und Nav-Cards per `mb-8`/`mb-12` zu vergrößern, blieb der sichtbare Abstand nahezu unverändert. Ursache per direkter Prüfung des von Vite ausgelieferten CSS bestätigt: Ein alter, aus dem electron-vite-Scaffold übernommener Reset (`*, *::before, *::after { margin: 0; ... }`) war nicht in `@layer base` eingebunden. Tailwind v4 nutzt CSS Cascade Layers (`@layer theme, base, components, utilities`) — nicht eingebundene („unlayered") Regeln gewinnen dabei grundsätzlich gegen jede Layer-Regel, unabhängig von Selektor-Spezifität. Der Reset hat dadurch potenziell **jede** `margin`-Utility-Klasse (`mb-*`, `mt-*` usw.) app-weit überstimmt, nicht nur an dieser einen Stelle. Zusätzlich war der Reset komplett redundant zu Tailwinds eigenem, bereits korrekt in `@layer base` eingebundenem Preflight (das setzt `box-sizing`, `margin: 0` und `list-style: none` für `ul`/`ol`/`menu` schon selbst). Fix: redundanten, unlayered Reset entfernt, das einzige zusätzliche Detail (`font-weight: normal`) korrekt in den bestehenden `@layer base`-Block verschoben. Nach dem Fix wirkt `mb-12` wie erwartet, per Screenshot bestätigt. `npm run typecheck` und `npm run lint` weiterhin sauber.

Die Verdrahtung mit der echten `db`-Instanz und der `ensureTeamMembersTable(db)`-Aufruf wanderten stattdessen in `registerTeamHandlers()` (`src/main/ipc/teamHandlers.ts`).
